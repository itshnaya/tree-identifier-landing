# Dossier prêt pour Claude Code — préparation des images

Ouvrir ce dossier dans Claude Code, puis lui donner le brief complet de la landing. Les consignes locales sont dans `CLAUDE.md`.

## Présent

- `assets/logo.png` : logo fourni par Claire, copié sans modification.
- `assets/app-screen-1.png` à `app-screen-3.png` : trois visuels officiels iOS, 1287 × 2796 pixels.
- `assets/android/` : trois alternatives officielles Android.
- `store-links.json` : les liens exacts Google Play et App Store.
- `asset-sources.json` : les sources des images et leur plateforme.

Les visuels officiels comprennent des titres et des mises en scène promotionnelles. Si le brief exige des captures brutes sans habillage, il faudra les fournir depuis l'app.
